# My agent: Smart Recipe & Meal Coach
One-liner: A conversational agent that helps home cooks plan meals, track pantry ingredients, and discover recipes with a catalog of curated recipes and meal plans.

Tool coverage:
- Memory: Remembers user dietary preferences, allergies, disliked ingredients, and pantry inventory across sessions.
- Tools: Looks up recipe database, searches for ingredients, and logs meals or pantry updates.
- Catalog/UI: Recipe cards, nutritional tables, and weekly meal plan overviews rendered with A2UI.
- Image gen: Generates appetizing visuals of finished dishes and plating previews.
- Sandbox: Computes nutritional macros, caloric totals, and ingredient scaling ratios using Python code execution.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for macro calculations, live recipe/grocery API lookups.
